# 咫牌 · 微表情与妆面

这是卡面设计方案，还没有写进游戏。微表情和妆面分开：微表情只改眉、嘴和极淡的气色；妆面是面上的妆、伤和水迹，可以叠在微表情上面。

头型、眼位、圆点眼都与现行卡面一致。官方肤色为 `#f3d2b8`，墨色为 `#241c16`，圆点眼在 `(±6, -1)`，半径 `2.2`。

## 图纸

- [现行妆面对照](00-makeup-current.png)：现在游戏里实际在用的七种妆面，以及浅、苍、棕、深、白五种肤色底。其中「苍白」目前只换了嘴，脸没有变白；「涂白」目前是红颊和深色嘴，并没有白粉。
- [二十一微表情](01-micro21.png)：静、思、凝、听、息、疲、冷、笑、暖、羞、怜、哀、痛、决、凛、疑、讽、拒、惊、怒、喊。「喊」是这一套里唯一张大的嘴，其余都保持微差。
- [十四妆面](02-makeup14.png)：胡须、短髭、厚唇、红妆、残妆、酒色、苍白、涂白、血痕、伤痕、泪痕、水痕、汗颜、尘灰。按五百张卡里会用到的妆补齐。「涂白」改成真正的白粉，下巴留一圈皮肤，避免看成纸人；「苍白」改成真正的淡面。血痕和伤痕已按优化后的画法绘制。
- [血痕与伤痕对照](03-wound-revise.png)：左边是优化前的直线画法，右边是优化后的。血痕带浓淡和滴落；伤痕是浅色旧缝。
