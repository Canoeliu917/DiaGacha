## 四星以上出场动效（重点加强）

用户反馈：四星以上出场不够惊艳，动效不够。v20 只有卡面柔光、按钮不再换色——这一次要在「剧场性」上加码，但仍克制，不要赌场闪片、不要高饱和彩虹描边、不要把「看安利 / 跳过动画 / 上一张 / 看这一台」托盘改色。光和动效都落在卡/开包卡区。

按稀有度分层（以该张正在翻开的卡为准；若要给整包气氛，只取包内最高档，且只作用于卡区）：

- 头牌（4 / SR）：约 420ms，卡由 0.92 放大到位并略上移落入，冷蓝边光Sweep 一次（左上到右下），阴影加深。可有极轻的一声提示音（未静音时）。
- 压轴（5 / SSR）：约 700ms，紫气只铺在卡后，光圈如幕启或光圈打开，少量缓慢尘粒（几颗，优雅，禁止礼花式乱闪），再多停约 200ms。
- 独步（6 / UR）：约 900ms，从中心呼出暖金，薄金边落定，卡如走进光里（translateY 约 16px→0 + fade），金粉尘粒更慢，余晖约 2s 后回到静息金边。
- 绝唱（7 / LR）：约 1200ms，最隆重：场光略暗、只留这张卡；虹彩边缓慢流转；从卡心扩出一圈光环后消失；8–12 颗慢尘粒；未静音时可有独特的一声sting。静息保留低幅度虹彩呼吸。

三星及以下保持现有克制翻法。最高三档的翻卡等待、下一张与跳过确认逻辑保留。`prefers-reduced-motion` 时取消循环与尘粒，只留一次性的静帧边光。静音只关声音，不关动画（减动偏好才关循环动画）。不要引入新的大型动画库，用 CSS + 现有 JS。
