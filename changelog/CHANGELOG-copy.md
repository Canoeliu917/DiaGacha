# DiaGacha 文案更新

依据同目录《文字优化方案.txt》，将文案调整为具体、克制、略带冷幽默的节目单口吻。

## 改动范围

- 卡池仍为五维各 100 张。补齐或改写简介、戏剧小注、看点、排演建议；剧目以人物、事件及处境为主，事实与假想改编分开。
- 五卡示范写入卡池：《蔡文姬》保留归乡、骨肉离别和承续父业；舞剧以动作、节奏及编舞展开关系；烟雾先解释视觉作用；安提戈涅保留违令葬兄的原作身份；洛曼家厨房说明日常与回忆的交错。
- 名词解释使用显式词典，重新配对卡片标签。删除按词尾猜定义、截断人名和把普通词包装成术语的路径。最高任务、人物弧光、第四堵墙与间离术分别解释。
- 《厨桌归汉》使用方案完整示范；同一组卡稳定生成同样文字。其他组合及替换卡使用各卡的实际含义与排演动作，避免仅改静态示例。
- 剧名不再强求四字，一句话保留底本或人物及具体舞台变化。演后谈明确使用“这一局”“若排在”等假想改编标志。
- 简评改为“看点／险处”；只有可明确对应原作的角色与场所联系才标“彩蛋”。不把借角、借景本身写成创作缺点，不使用“X一停……”式综评。
- 对用户显示“演法／舞台手段／登场角色／演出空间”；内部维度键沿用原值。数值仍沿用原游戏规则，并明确其只是游戏组合参考，不是作品或人物价值的评判。

## 关键函数与对象

| 名称 | 用途 |
| --- | --- |
| 卡池 `e` | `blurb`、`note`、`observe`、`stage`、`action` 等文案数据；剧目另有 `plot`、`titleCue`，100 种手段各有具体 `risk` |
| `copyGlossary`、`Ft` | 真实术语词库及精确查询，取消按字面猜义 |
| `xn` | 按“戏剧小注／看点／试着这样排”呈现详情 |
| `copyPlaceTitles`、`copyTitle`、`h`、`_` | 混搭标题、概括及示范副标题 |
| `copyBeat`、`copyEffects`、`copyCase`、`nn` | 读取具体动作和手段的观看效果、识别完整示范、生成演后谈 |
| `copyFromPlay` | 结合小注明示的来源和已核对的角色出处确认原剧关系，不将通用场所误认成特定原剧场景 |
| `copyReview`、`Xt`、`On` | 组合看点、排演难处与有出处的彩蛋；分数与创作点评分开 |
| `Qt`、`copyDimension` | 五维提示及显示名称 |
| `ge` | 接受短看点和多句释义，避免为旧长度门槛填充废话 |

原有 CSS、卡图、卡牌 ID、稀有度、数值、分享编码及开包状态流程保留；尾页仍为五小横卡 → 这台 → 综评 → 演后谈。

## 抽查与验证

### 词条抽查

| 类别 | 词条 | 核对结果 |
| --- | --- | --- |
| 表演理论 | 最高任务、第四堵墙、间离术 | 区分人物总体追求、假想观演边界与促进判断的表达方法；不将间离解释为排斥情感 |
| 叙事概念 | 人物弧光、回顾式结构、闪回 | 区分人物变化、逐步揭示往事与暂时转入过去的场面；不按“光”字猜含义 |
| 舞台技术 | 顶光、侧光、舞台烟雾 | 分别解释入射方向与阴影、身体轮廓、显隐及空间清晰度；不套用“演员看不看观众” |
| 戏剧样式 | 舞剧 | 以舞蹈、身体关系与编舞推进情节，不等于插舞，也不要求绝对排除语言 |

### 五维台抽查

《蔡文姬》＋舞剧＋烟雾＋安提戈涅＋洛曼家厨房生成《厨桌归汉》，概括为：

> 安提戈涅借演《蔡文姬》：归乡改用舞步，洛曼家的厨房先别急着开饭。

演后谈保留归乡与骨肉离别，说明安提戈涅带来自己原剧中的坚持；舞剧落实为迈步、回身，厨房落实为门口、饭桌、空椅，薄烟留在门外而不遮挡告别动作。简评为方案中的“谁能决定告别”及“别遮住舞者那次回身”。

分别将五个维度替换为《等待戈多》、史诗剧场、顶光、娜拉、乡间小路，均生成不同的演后谈。另抽查《等待戈多》与转台、《雷雨》与歌队等具体碰撞。

### 自动与浏览器检查

- 500 张卡通过启动数据校验；全部标签命中 143 条显式术语字典。
- 100 套确定性组合覆盖五维的全部卡片，检查生成文本、旧套话、禁用句式与尾页结构。
- 1,000 套组合与原版评分相同；卡牌 ID、顺序、维度、稀有度、数值与数值轴未改。
- 原版 CSS、嵌入位图与 SVG 保持一致。
- Chrome 实际走通首页 → 综合包 → 开包 → 五次翻卡 → 结果 → 分享链接 → 详情 → 名词解释，未出现运行异常。
- 390px 手机宽度与 1280px 桌面宽度审图通过，五张卡保持横排，无横向溢出，compact 尾页顺序不变。

附 `check-copy.cjs`，在本目录执行 `node check-copy.cjs` 可复查卡池、术语覆盖、100 套组合及 compact 结构，不需安装依赖。
