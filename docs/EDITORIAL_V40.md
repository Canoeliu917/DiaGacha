# 演后谈与卡牌介绍的编辑依据

演后谈把跨作品人物放进明确标注的虚构故事，同时保留独立的戏剧知识介绍。虚构情节不能被表述为原作剧情，写作方法参考也不构成专家对游戏分数的背书。

## 编辑取舍

- 写清人物的具体愿望、阻力、选择及后果；配角也有自己的立场。
- 每次转折由可理解的事件引起，不以换位置、重新排练、先后行动等指令代替剧情。
- 人物保留原作来源和已有的标志特征；演法、手段、空间参与事件，科普段说明其真实定义或作用。
- 低星可以更简洁，但保留身份或定义、来源和代表特征。高星增加背景及延伸解读，不垄断基本知识。
- ATK、DEF 是游戏编辑判断。解释具体优势与适用边界，不用稀有度倒推分数；资料不足以证明旧低分时明确保留不确定性。

## 专业写作参考

- [Tom Holloway：人物写作（Bush Theatre）](https://www.bushtheatre.co.uk/news/the-student-guide-to-playwriting-characterisation/)：把人物放回具体处境，考虑其欲望、阻碍和结果，次要角色同样需要考虑。
- [Jennifer Tuckett：场景写作（Bush Theatre）](https://www.bushtheatre.co.uk/news/student-guide-to-playwriting-scenes/)：用欲望、冲突和改变局面的事件组织场景。
- [Writing a scene（Old Vic）](https://www.oldvictheatre.com/discover/the-hub/independent-learning/introduction-to-playwriting/writing-a-scene/)：双方各有目标和理由，局面变化会影响人物争取目标的方法。

这些是本产品参考后作出的编辑取舍，不是适用于所有戏剧的唯一公式。

## 本次示例的原作与演出资料

- [萧伯纳《华伦夫人的职业》原作](https://www.gutenberg.org/files/1097/1097-h/1097-h.htm)：理解母亲早年的贫困处境，与接受她继续经营妓院获利，是薇薇面对的不同问题；她最终选择经济独立。
- [《艺术》作品介绍（Concord Theatricals）](https://www.concordtheatricals.com/s/13005/art)：塞尔吉购买的昂贵白画引发朋友争执，品味分歧逐渐危及友谊。
- [《艺术》复排剧评（AP）](https://apnews.com/article/cad36d5e3c340bcb0101604163c7f999)：关于朋友间支配、独立与竞争的解读可供参考，但特定版本的演出不能当作角色唯一的原作事实。
- [《骆驼祥子》官方演出资料](https://www.hall.tsinghua.edu.cn/info/yc/2323)：刘四爷的作品来源为老舍《骆驼祥子》。
- [《桃花扇》官方演出资料](https://www.hall.tsinghua.edu.cn/info/yc/3072)：媚香楼属于李香君、侯方域的叙事语境。

外部资料核查覆盖本次编辑方法与上述示例。500张常驻卡的检查覆盖介绍完整性、角色来源字段及显示保留情况，不应宣称全部内容已经专业剧评人逐条审核。
