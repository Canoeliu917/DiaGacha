## 第一刀：软保底与回来的理由

- 只计综合卡池（六维成台）。分享链接浏览不计。单维包不计。
- 约 30 包内必出至少一张压轴及以上；约 60 包内必出独步或绝唱。
- 自然出货会重置对应计数；保底触发后也重置。独步保底同时满足压轴保底。
- 开包页可见：「再开 x 包，必出压轴以上」「再开 y 包，必出独步或绝唱」。
- 计数存在独立键 `diamasha.loop`，不覆盖 `diamasha.owned` 或 `diamasha.tasks`。
- 今日赠礼（Asia/Shanghai 自然日）：可领一次更好机会的下次综合包 + 1 次单维包，显示「今日已领」。不领取也不限制平常无限开包。不是体力。
- 收集节点 100 / 300 / 500 / 706：一次性自选维度，下次综合包该维必出压轴以上，并解锁长图印记。不改 T 或「这台」分数。
- 首页与顶栏可直接看到单维包任务进度，不必先读完演后谈。读演后谈仍可领取原任务。

## 第二刀：短图 / 长图、分享落地、可读演后谈

- 「生成短图」：六张小卡、六芒星、这台、剧名、一两行综评。不含完整演后谈。
- 「生成长图」：现行完整节目单，含全文演后谈与看点/险处。
- 均为离线 html2canvas，逻辑宽度 390、scale 2，导出 780px。品牌「咫牌」留在图上。
- 分享 `#m=` 落地页顶部有「我也开一台」：进入综合卡池封皮，在对方真正开包前不销毁分享阵容；浏览器返回仍可看到原链接（未清 hash）。旧五卡链接仍是五卡、五芒星、「这一台没有配角入册」，分数与演后谈与 v21 一致。
- 演后谈默认 120–180 字短场面（谁 / 哪 / 争执），「展开全文」后看空间条件、演法与手段、短评式的艺术性与戏剧性。短层避免直接抛出「假定性」「间离」「观看契约」。

## 第三刀：不重复的演后谈结构

- 对手戏仍是核心，但不再固定「底本 → 对手戏 → 空间 → 演法 → 艺术性」的顺序。
- 按该台最强冲突起笔（对手戏 / 底本 / 空间），并用牌面 id 稳定选择多种开场与收束。
- 展开层的艺术性/戏剧性写成短评，不加「艺术性：」标签。
- 看点 / 险处仍是独立判断，不是演后谈摘句。音乐剧分支仍走歌唱约定。

## 高星颜色与出场（4 星起）

头牌 / 压轴 / 独步 / 绝唱的边框、光晕、卡框更饱和；龙套/班底/当行保持克制。按钮托盘仍是纸色。效果只在卡面区。

翻开前增加蓄势等待（充电、压暗、延迟翻开）。`prefers-reduced-motion` 会关掉循环与粒子；静音只关声音。

单次「跳过动画」仍不会默默抹掉后面压轴以上的单独亮相，除非再确认「全部跳过」（与 v21 压轴+规则一致）。头牌有蓄势，但不加入「必须看完或确认跳过」的拦截。
