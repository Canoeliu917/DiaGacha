### 《厨桌归汉》 · 归乡的路，告别的人

蔡文姬 / 舞剧 / 烟雾 / 安提戈涅 / 洛曼家厨房

这一局，《蔡文姬》的归乡与骨肉离别，遇上了安提戈涅。一个要离开亲人回乡，一个宁可违抗禁令也要安葬兄长；归途已经有了方向，谁能决定告别却成了难题。

借来的洛曼家厨房还带着《推销员之死》的旧梦：今天的饭桌旁，往事随时会来落座。若这两种执念在此相遇，一顿团圆饭便可能变成谁也不肯先走的告别。舞剧里的拉住与挣脱替争辩接了话；烟雾中，门口的人影越来越淡，桌边的牵挂却没有散。

归乡的路缩短了，告别一点没省。

### 《转了一圈，还在等》

等待戈多 / 荒诞派 / 转台 / 娜拉 / 娜拉的客厅

《等待戈多》原本讲的是：弗拉季米尔和爱斯特拉冈在树旁等待戈多，来客几度出现，要等的人始终未到。这一局，娜拉带着另一出戏的处境闯入：易卜生《玩偶之家》中的人物。她曾秘密借债挽救丈夫的健康，危机使她认清婚姻中的不平等，决定离家。

若故事发生在娜拉的客厅，娜拉的客厅温暖，有圣诞树，每扇门却通向丈夫的规则，屋子越像样，摔门越响。荒诞派里，娜拉问了一遍又一遍，回答兜回原处，眼前的难题始终没有过去。

转台之下，等候的人没挪脚，同一扇门却又从眼前经过。一个决心离开的人，偏偏闯进了谁也走不了的等待：门就在眼前，明天却总比出门早到。

### 《周家的事，全城的耳朵》

雷雨 / 史诗剧场 / 歌队介入 / 哈姆雷特 / 裕泰茶馆

《雷雨》原本讲的是：周、鲁两家的旧事在雷雨前夕相撞，父权、阶级与隐瞒的血缘把几段感情推向悲剧。这一局，哈姆雷特带着另一出戏的处境闯入：莎士比亚同名悲剧中的丹麦王子。他追查父王死亡的真相，借装疯和戏中戏试探叔父，复仇不断牵连他人。

若故事发生在裕泰茶馆，裕泰茶馆这间屋子几乎不改，进来的人和时代从清末换到抗战之后，空间成了历史的容器。史诗剧场里，哈姆雷特的私事成了众人的公案，原本理所当然的规矩也要接受追问。

歌队介入之下，一个人的承诺有了集体回声，私事便被放到众人面前。一个非要追到真相的人，遇上一群靠旧事未被说破才维持体面的人；每句追问，都可能拆掉一个人的生活。
