DiaGacha · 咫牌：人物优先与图形化界面设计预览（V10）

打开 index.html 即可体验，无需安装依赖或联网。
这是固定六张示例卡的设计记录，未接入真实概率、账户、收藏或正式游戏。

操作
- 点击红线、聚焦后按 Enter/Space，或向右拖动至少70px抽卡。
- 不足阈值时回弹；触发后约2.6秒牵出六卡并逐次翻开。
- 回旋箭头重播，左箭头返回主页。问号展开预览说明。
- 系统启用减少动态效果时直接展示结果。
- 图形控件保留aria-label、title与键盘焦点；状态播报对读屏可见。

视觉
- 首页使用完整效果图与透明热点，保留选定的中英文字感、人物与比例。
- 六卡使用完整卡面图裁剪，保留小号连笔空心星及卡名字形。
- 人物轮廓优先，舞台/房屋减淡；红线用于服装、道具、姿态和动向。
- 结果页去掉重复副标题与常驻说明，以“碰撞”、短分数标签和红黑图形组织内容。
- 5/3/2/4/4/4星与73、+3、+0、76为固定示例；精简文字不改变真实游戏规则。

素材
- 效果图由内置image_gen生成，具体规则见上级DESIGN.md。
- HTML外围文字使用霞鹜漫黑（LXGW Marker Gothic）woff2子集。
- 来源：https://github.com/lxgw/LxgwMarkerGothic
- 许可：assets/OFL-LXGW-Marker-Gothic.txt。
