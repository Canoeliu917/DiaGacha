# DiaGacha 卡牌评价规则

本规则说明攻防、单卡综合分、文化参考分与星级的含义。分数是服务于戏剧混搭游戏的编辑判断，方便比较卡牌的不同作用，不是作品、人物或剧作家的客观价值排名。资料机构提供事实与实践依据，不为本游戏的数值背书。

## 1. 六维攻防

ATK 衡量元素带来的推动或改变，DEF 衡量其辨识、执行与支撑能力。两者不是战斗力、道德评价或现实知名度。每个轴均由三个子项组成，子项依次对应下面的编号。

| 维度 | ATK：三个子项 | DEF：三个子项 |
|---|---|---|
| 剧目 | **冲突强度**：①目标或处境的牵制；②选择产生的后果；③场面推进或有意义的延宕。 | **叙事完整**：①结构自身的组织逻辑；②行动、人物与主题的照应；③结尾或开放结构对前文的回应。 |
| 风格体系 | **风格冲击**：①改变观看方式；②重组身体、语言或声音；③产生可说明的新解释。 | **方法成规**：①原则清楚；②能转化为排练行动；③可重复实践且适用边界明确。 |
| 导演手法 | **调度新意**：①改变关系呈现；②重组时间、空间或注意力；③产生与主题相关的结果。 | **手法成法**：①操作条件清楚；②效果可被观众辨认；③能够稳定复现。 |
| 主演 | **人物行动**：①欲望可理解；②选择改变局面；③承担行动后果。 | **身份辨识**：①处境与声音明确；②内在矛盾可以表演；③变化仍符合人物逻辑。 |
| 配角 | **对戏力度**：①有独立意图；②施压、阻挡或支持对方；③揭示或反衬主题。 | **关系辨识**：①关系位置清楚；②关系产生可见后果；③功能独特、不能任意替换。 |
| 环境 | **空间错位**：①改变出入与距离；②改变谁能看见或听见谁；③新条件产生关系变化。 | **空间承载**：①支持走位、人数与进出；②视听和物件条件明确；③承托多种行动。 |

“完整”不要求线性、封闭结局或单一英雄；“行动”也包括有意义的等待、拒绝与迟疑。《等待戈多》的循环、《樱桃园》的群像与延宕，应按各自的结构判断。配角和通用技法可以有很强的作用；反派不因行为恶劣扣分，空间不因地名冷僻加分。

## 2. 子项量表与单卡分

| 子项 | 判断标准 |
|---|---|
| 0 | 已有内容显示该项基本不成立。 |
| 1 | 作用较弱，条件苛刻，需要大量外部补写。 |
| 2 | 作用明确，能在具体场景中成立。 |
| 3 | 作用较强，有多个具体实例或完整实践可说明。 |
| 4 | 在该项上具有鲜明示范性，有具体文本或实践支撑。 |

每轴按 `50 + 4 × 三项之和` 计算，新量表范围为 50–98。例如，`[3,3,3]` 得 86，`[4,3,3]` 得 90，`[4,4,3]` 得 94。不能只因作品著名就把三项填满；资料不足也不等于该项为零，应保留未复核状态。

单卡综合分为 `T = round((ATK + DEF) / 2)`。T 不再叠加名气、星级或稀有度底分；改变收藏等级不会反过来抬高攻防。能力强但文化参考较普通的卡，仍能保留其实际作用。

## 3. 文化参考分 reference

reference 采用 0–100 的编辑尺度，回答“这张卡作为戏剧文化条目有多强的参考价值”。判断综合考虑：持续创演与传承、教学和研究中的位置、形式或人物创造的贡献，以及跨时代、跨地区的影响。应说明来源支持的是作者、具体作品、角色、方法还是空间，不能相互替代。

| 区间 | 编辑判断的解释 |
|---|---|
| 0–49 | 本轮没有使用的保留区间；不能因缺少资料就自动归入。 |
| 50–59 | 基础、泛用条目的参考起点，或尚未专题复核的历史基线。 |
| 60–69 | 专业实践中有明确用途或位置。 |
| 70–79 | 本领域成熟且重要，有具体实践可说明。 |
| 80–89 | 具有代表性，作用、实践或影响得到多方面支持。 |
| 90–96 | 标志性作品、人物、方法或空间，有鲜明贡献与持续实践依据。 |
| 97–100 | 极少量最高参考锚点，必须给出独立、具体的理由。 |

这些区间帮助解释判断，不按网页数量机械加分。同一机构的多个页面不等于多个独立意见；教学收录能证明教学使用，不能自动证明“世界第一”。作家的奖项也不能让其全部作品和人物继承最高分。不同文化传统不必获得同一种奖项，才有资格成为重要参考。

逐卡理由至少交代：资料具体证明什么、这张卡在本维度有什么作用、哪些判断仍属于编辑解释。只有剧情介绍时，可以据此分析关系和行动，不能改写成机构赞誉；只有获奖记录时，可以确认获奖，不能宣称已读完原作并分析全部场面。参考分的调整应能追溯到具体理由，既允许新材料带来修订，也保留合理的不同意见。

## 4. 策展指数、星级与颜色

策展指数为 `0.6 × T + 0.4 × reference`。用未取整的指数判档，边界包含下限。星级与稀有度、边框颜色保持一一对应；它们表示本游戏的收藏等级，不能再作为单卡综合分的额外加分。

| 策展指数 | 等级 | 星级 | 边框 |
|---|---|---:|---|
| 小于 60 | 龙套 C | 1 | 灰 |
| 60 至小于 66 | 班底 UC | 2 | 银 |
| 66 至小于 72 | 当行 R | 3 | 绿 |
| 72 至小于 78 | 头牌 SR | 4 | 蓝 |
| 78 至小于 84 | 压轴 SSR | 5 | 紫 |
| 84 至小于 90 | 独步 UR | 6 | 金 |
| 90 及以上 | 绝唱 LR | 7 | 彩虹 |

## 5. 33 张锚点与历史初评

其余 **744 张仍为历史编辑初评**，没有完成本轮逐卡文献审定。存在原始记录时取回 `old` 中的攻防，撤销此前按名气产生的数值膨胀；没有原始记录则保留已有值。历史攻防不反推成新量表子项，也不冒称经过同样复核。

同一原作的剧本、角色和空间分别评价。例如，《樱桃园》的结构完整性、洛巴辛的对戏推动、樱桃园空间的承载，属于不同问题；共享作品来源不要求同分。锚点中保留这种差异，让经典作品得到恰当参考，也让具体功能较强的普通条目有自己的位置。

这些卡的历史 fame 统一迁移为 reference：`100→94、96→88、90→82、84→76、78→68、64→58、50→50`。这是保持可比较性的编辑基线，不是新文献结论。后续补证时应同时记录事实范围与改分理由，不能只因一次检索无结果就贬低条目。
