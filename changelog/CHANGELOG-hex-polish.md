# DiaGacha 六角 UI 精修

参考：`feedback-pills.jpg`。修改文件：`DiaGacha-mvp-index.html`。

## 本轮调整

- 删除卡详情「为何值得收」整块，包括其内部掉率、数值说明和「稀有与分数，怎么算」折叠。保留戏剧小注、看点、原有分级知识。
- 保留「排演参考（可选）」，默认折叠，可正常展开和收起。
- 删除尾页「为何得到这个分数」折叠及其说明，同时移除图下重复的均分算式。
- 六芒星面板圆角改为 18px；图宽上限从 340px 收至 320px，图形半径从 92 收至 76。两枚三角形使用二次曲线圆角，网格、轴线、数据线和填色减淡。
- 五小卡下间距从 12px 收至 4px；取消图内独立标题，压缩图高与上下留白，使六角紧贴五小卡。
- 删除五维速览 pill 行和点击后的小注行。五点直接并入六角：剧目·底本、演法、手段、主演·借演、空间·借场；演法和手段不重复文字。原剧角色或原景仍据实显示「原剧」「原景」。
- 前五角使用原生按钮打开对应卡详情，支持触摸、键盘及可见焦点。第六角「碰撞」点击显示本局加减分轻提示。
- 六角保留实际分值，图下保留碰撞独立量尺提示；第六角未改为百分制。
- compact 主顺序保留：五小卡 → 六芒星 → 这台 → 综评 → 演后谈；原剧名、看点／风险和分享区继续保留。

## 验证

- `node check-copy.cjs` 通过：500 张卡、标签释义、100 套组合及 compact 结构。
- `node check-hex.cjs` 通过：500 张详情、1,000 套六角读数、精确总分、正／负／零碰撞及尾页顺序。更新该已有检查以匹配按钮标签和已删除的区块。
- 与本轮修改前快照对照：500 张卡数据、1,000 套完整组合结果一致；未改开包流程、抽取概率、评分公式或分享编码。
- Chrome 无头浏览器检查 390／320／430／1280px：文档宽度与视口一致，并逐一检查结果页可见子元素边界，无横向越界。
- 在 390px 逐个点击前五角，均打开正确卡详情；排演参考默认关闭且展开／收起正常；详情无横向越界。键盘 Enter 点选、碰撞 −9 提示、分享链接重载通过，无 JavaScript 异常。
- 示例组合六角读数仍为 85／69／78／87／75／−9，最终分仍为 70。
