# DiaGacha 卡牌评价规则

本规则说明攻防、单卡综合分与星级的含义。分数是服务于戏剧混搭游戏的编辑判断，方便比较卡牌的不同作用，不是作品、人物或剧作家的客观价值排名。资料机构提供事实与实践依据，不为本游戏的数值背书。

## 1. 六维攻防

ATK 衡量元素带来的推动或改变，DEF 衡量其辨识、执行与支撑能力。两者不是战斗力、道德评价或现实知名度。每个轴均由三个子项组成，子项依次对应下面的编号。

| 维度 | ATK：三个子项 | DEF：三个子项 |
|---|---|---|
| 剧目 | **冲突强度**：①目标或处境的牵制；②选择产生的后果；③场面推进或有意义的延宕。 | **叙事完整**：①结构自身的组织逻辑；②行动、人物与主题的照应；③结尾或开放结构对前文的回应。 |
| 风格体系 | **风格冲击**：①改变观看方式；②重组身体、语言或声音；③产生可说明的新解释。 | **方法成规**：①原则清楚；②能转化为排练行动；③可重复实践且适用边界明确。 |
| 导演手法 | **调度新意**：①改变关系呈现；②重组时间、空间或注意力；③产生与主题相关的结果。 | **手法成法**：①操作条件清楚；②效果可被观众辨认；③能够稳定复现。 |
| 主演 | **人物行动**：①欲望可理解；②选择改变局面；③承担行动后果。 | **身份辨识**：①处境与声音明确；②内在矛盾可以表演；③变化仍符合人物逻辑。 |
| 配角 | **对戏力度**：①有独立意图；②施压、阻挡或支持对方；③揭示或反衬主题。 | **关系辨识**：①关系位置清楚；②关系产生可见后果；③功能独特、不能任意替换。 |
| 环境 | **空间错位**：①改变出入与距离；②改变谁能看见或听见谁；③新条件产生关系变化。 | **空间承载**：①支持走位、人数与进出；②视听和物件条件明确；③承托多种行动。 |

“完整”不要求线性、封闭结局或单一英雄；“行动”也包括有意义的等待、拒绝与迟疑。《等待戈多》的循环、《樱桃园》的群像与延宕，应按各自的结构判断。配角和通用技法可以有很强的作用；反派不因行为恶劣扣分，空间不因地名冷僻加分。

## 2. 子项量表与单卡分

| 子项 | 判断标准 |
|---|---|
| 0 | 已有内容显示该项基本不成立。 |
| 1 | 作用较弱，条件苛刻，需要大量外部补写。 |
| 2 | 作用明确，能在具体场景中成立。 |
| 3 | 作用较强，有多个具体实例或完整实践可说明。 |
| 4 | 在该项上具有鲜明示范性，有具体文本或实践支撑。 |

每轴按 `50 + 4 × 三项之和` 计算，新量表范围为 50–98。例如，`[3,3,3]` 得 86，`[4,3,3]` 得 90，`[4,4,3]` 得 94。不能只因作品著名就把三项填满；资料不足也不等于该项为零，应保留未复核状态。

单卡综合分为 `T = round((ATK + DEF) / 2)`，先四舍五入为整数，再直接决定星级与稀有度。T 不叠加名气、历史文化备注或稀有度底分；不为保住某个星级倒推攻防。所有维度使用同一分档。

## 3. 历史文化备注 reference

`reference` 仅为旧版保留的文化参考记录，供追溯编辑背景；**不影响 ATK、DEF、单卡综合分、星级、稀有度或抽取概率**。旧版曾综合持续创演、教学研究、形式贡献和影响记录这个值，本版不再以它形成第二套判星标准。

资料必须区分作者、具体作品、角色、方法和空间。同一机构的多个页面不等于多个独立意见；教学收录能证明教学使用，不能自动证明“世界第一”。作家的奖项也不能让其全部作品和人物继承最高分。不同文化传统不必获得同一种奖项，才有资格成为重要参考。

逐卡复评至少交代：资料具体证明什么、这张卡在本维度有什么作用、哪些判断仍属于编辑解释。只有剧情介绍时，可以据此分析关系和行动，不能改写成机构赞誉；只有获奖记录时，可以确认获奖，不能宣称已读完原作并分析全部场面。攻防调整须有相应子项与理由，既允许新材料带来修订，也保留合理的不同意见。

## 4. 综合分、星级与颜色

整数综合分 T 直接判档。星级与稀有度、边框颜色一一对应，既不另算策展指数，也不按名气修正档位。例如，75 分必为 4 星，80 分必为 5 星，90 分必为 7 星。

| 整数综合分 T | 等级 | 星级 | 边框 |
|---|---|---:|---|
| 0–59 | 龙套 C | 1 | 白 |
| 60–65 | 班底 UC | 2 | 绿 |
| 66–71 | 当行 R | 3 | 蓝 |
| 72–77 | 头牌 SR | 4 | 紫 |
| 78–83 | 压轴 SSR | 5 | 橙 |
| 84–89 | 独步 UR | 6 | 彩虹粉 |
| 90–100 | 绝唱 LR | 7 | 炫光黑 |

没有复评记录的卡保留当前有效攻防，标明历史编辑初评；本轮迁移不会重新取回 `old` 数值，也不会覆盖已经确认的复评。历史攻防不反推成新量表子项，不冒称经过同样复核。全部卡均按当前 T 统一判星；评分迁移本身不更改 ID、原始数组顺序或图鉴编号，编号可由独立的图鉴编排流程调整。

同一原作的剧本、角色和空间分别评价。例如，《樱桃园》的结构完整性、洛巴辛的对戏推动、樱桃园空间的承载，属于不同问题；共享作品来源不要求同分。锚点中保留这种差异，让经典作品得到恰当参考，也让具体功能较强的普通条目有自己的位置。

早期版本曾把 fame 迁移为 reference：`100→94、96→88、90→82、84→76、78→68、64→58、50→50`。这里只保留迁移历史，不重新执行，也不把它作为本版分数或星级依据。后续补证时应记录事实范围与改分理由，不能只因一次检索无结果就贬低条目。
