# v55 主标题目录

新增 **112 条完整主标题**，去掉地点前缀后仍为 112 条；与 v54 旧 224 条字面重合 0 条。每条先匹配当前故事分支和指定人物的显式行动取向，再按完整卡组确定性选取。名称、稀有度、分数不用于假造人物个性。
