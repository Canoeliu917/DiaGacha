# DiaGacha v36 · 评分与稀有度（SCORING-v36）

v36 把「名作地位」——历史地位、作家水平、传唱度——放进稀有度和单卡分，让中外名家名作和他们的经典人物稳稳站在最高档；这台分也让稀有度和最强的几张卡说话更响。卡数（777）、卡名、id、维度、短文都不变；各档抽取权重和保底规则不变。

v36 steering（用户 t161）的具体规则（`score-v36.py`）：
- 剧本、主角维度里 F=90 的卡 → F=96（绝唱）；
- 剧本维度里 F=84 的卡 → F=90（独步）；
- 经典剧作的标题/核心主角（费德尔、克莉奥佩特拉、汉姆、斯多克芒、贝兰杰、卡捷琳娜、觉慧、伽利略、理查三世、沃伊采克 等 19 张）F=84 → F=90（独步）。

## 2. 稀有度

1. F≥96 → 绝唱 LR；F=90 → 独步 UR；F=84 → 压轴 SSR（下限，名作不会低于此档）。
2. 其余卡在**各自维度内**按 Q = 0.5·F + 0.25·ATK + 0.25·DEF 排序，按比例 压轴4 : 头牌23 : 当行28 : 班底24 : 龙套21 切分（每个维度都保留完整的低档池，抽卡 fallback 不变）。
3. 被提档的卡把数值抬到与档位相称：v' = max(v, round(L + v·(100−L)/100))，L = 95（F=100）、80（LR）、72（UR）、64（SSR）；再按档封顶 C82 UC86 R90 SR93 SSR96 UR98 LR99。

## 3. 单卡综合分 T

```
T = min(99, round(0.3·ATK + 0.3·DEF + 0.2·F + 0.2·IE[rarity]))
IE = {龙套C:55, 班底UC:64, 当行R:73, 头牌SR:82, 压轴SSR:90, 独步UR:96, 绝唱LR:100}
（v35：T = round(0.4·ATK + 0.4·DEF + 0.2·IE)）
```

## 4. 这台分（演后谈）

```
n    = 六（或五）张卡 T 的平均
rk   = 六（或五）张卡 IE 的平均（稀有度）
top3 = 最高三张 T 的平均
star = min(12, Σ {压轴:1.5, 独步:3, 绝唱:4})
这台 = clamp(55, 99, round(0.25·n + 0.25·rk + 0.5·top3 + star + 组合加减))
组合加减：plus +3，egg +2，minus −3（不变）
```
v35 是按位置加权的 T 平均（剧本、主角更重）。v36 改为稀有度与最强三张主导：三张独步 + 三张低档的手牌在没有扣分组合时 ≥90（实测最低 95；遇到 minus 组合最低约 85）。全龙套约 60–64，全当行约 75–79。旧的 `#m=` 五卡分享链接照常解析、计分，只出五张，不会补出第六张（`check-v36.cjs` 有检查）。

## 5. 序号 No.001–777

- 全部 777 张按新 T 从高到低排序；同分依次按 F 高者先 → 巅峰榜顺序（哈姆雷特、俄狄浦斯、雷雨、周朴园、繁漪、茶馆、王利发、麦克白……）→ 未封顶的原始 T → id。
- 序号是卡面数据（`no` 字段），以小号 `No.001` 显示在大卡/详情的「综合」一行右侧，不挤左上角的稀有度标签，也不挤图下的维度和卡名；我的卡包与总图鉴的排序里新增「按序号」。
