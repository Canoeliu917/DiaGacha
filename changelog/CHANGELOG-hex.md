# DiaGacha 六芒星与稀有度阅读更新

依据 `NEXT-hex-rarity.md` 与 `feedback-hex.jpg`，面向分享给朋友圈的普通玩家调整。

## 卡详情

- 主体改为「戏剧小注 → 看点 → 分级知识 → 为何值得收」。保留每张卡已有的具体出处、含义和观看细节。
- 排演文字移入默认关闭的「排演参考（可选）」，默认阅读路径不显示排演指令。原数字轴移到评分折叠内，优先呈现知识。
- C / UC 保持简洁但完整的小注与看点；R / SR 增加一条已有术语解释；SSR 增加两条；UR 增加两条及完整双轴说明；LR 展开该卡全部已有术语及双轴说明。不为凑篇幅虚构术语。
- 每张卡显示等级基础掉率、综合分、较强数值轴及含义。掉率指抽中这个等级的基础概率，不冒充某张卡的单卡概率；缺级时仍沿用原就近取卡规则。
- 「稀有与分数，怎么算」可展开查看双轴、实际数字公式及分数含义。综合分仍为 `round(ATK × 40% + DEF × 40% + 稀有度底分 × 20%)`。
- 同步纠正帮助中“稀有度只影响概率和光效”的旧说明，补上它对综合分底分的影响。

## compact 尾页

- 顺序为：五小横卡 → 六芒星 → 这台总分 → 综评 → 剧名／五维速览 → 演后谈。
- 新图为内联 SVG，两枚相交三角形组成六芒星底图，叠加刻度、六条轴、数据多边形和数据点；无外链图表库。
- 六角依次为「剧目／演法／手段／主演／空间／碰撞」，各显示标签及分值；SVG 提供可访问名称、六项读数和量尺说明。
- 前五角沿用单卡综合分，满分 100。第六角是原组合规则的实际加减分，有正、负、零三种情况，半径按 −9～+12 换算；图下注明独立量尺及零点不在中心，不把它伪装成百分制能力。
- 图下直接显示均分、碰撞与最终分。展开「为何得到这个分数」可逐项查看命中的加减分原因；仍只计算原有前三项规则，均分加碰撞后四舍五入，最终限定 55～99。
- 旧五维信息行改成较轻的速览按钮，点击仍可读取对应卡名和小注。

## 关键函数

| 函数 | 本轮职责 |
| --- | --- |
| `xn(card)` | 分级小注／术语、稀有与分数说明、默认关闭的排演参考 |
| `zn(card, tag)` | 详情入口；知识主体前置，数值轴收入说明折叠 |
| `me()`、`Rn()` | 同步稀有度和详情阅读的帮助文案 |
| `hexBonus(rules)` | 复用原规则的 +3／+2／−3 计算碰撞加减分 |
| `on(cards, rules)` | 沿用原均分、取整和 55～99 限幅；调用共享加减分计算 |
| `Xt(cards)` | 除原结果外暴露实际参与计分的前三项 `rules` 与 `bonus` |
| `hexSigned(score)` | 展示加号、负号及零 |
| `hexReason(rule, cards)` | 按真实命中规则解释本局为何加分或扣分 |
| `hexRadar(cards, result)` | 六芒星 SVG、六角分值、量尺、均分算式与原因折叠 |
| `Un(state)` | 将六芒星插入五小卡和「这台」之间 |
| `kn(result, slot)` | 五维速览按钮与对应小注 |

## 保留边界

500 张卡的数据、ID、顺序、稀有度、数值、术语字典、开包流程、分享编码及卡框美术保持一致。原样式块保留，新增样式只作用于六芒星、详情知识区和尾页速览。未新增或扩展戏曲内容；新文案不用“X 一停……”句式。
