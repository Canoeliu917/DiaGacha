# v54 小范围邀请试玩

这轮面向 10–15 位没有戏剧基础的朋友和 1–2 位戏剧背景朋友。免费、免登录；分享由玩家自愿决定，不以传播换抽卡机会。内部自动测试和桌面浏览器检查不能代替下面的真实体验记录。

## 朋友实际完成一局

请先让玩家独立操作，卡住时再说明。记录卡住的位置，不把主持人的帮助算作“自行玩懂”。

1. 打开邀请链接，说明自己认为这是怎样的游戏。
2. 开完第一包，读出故事里谁想做什么、受到什么阻碍、最后改变了什么。
3. 查看两张候选的卡面、星级、卡组分和故事，预览后只确认一张；说明为什么这样选。
4. 返回首页，找到收藏、称号印记和最近节目单；刷新后再次打开刚才的故事。
5. 自愿生成图片或复制链接。请玩家自己判断愿不愿意发给朋友，不提示“应该分享”。

普通玩家反馈只问四件事：哪一步不知道该点什么；故事哪一句看不懂；换卡是否让人想再试一场；愿意分享哪一张图、为什么。

戏剧背景玩家额外核对：卡片资料中的事实和专业名词是否正确；六维是否实际影响事件；跨作品故事是否被误认为原剧剧情；有没有擅自让无声人物开口、把群体写成一个人、人物前后动机冲突。

## 发现问题时

首页「问题反馈」可复制版本、当前卡组链接和浏览器信息。配上截图、点击步骤和预期结果，交给邀请人即可；游戏不会代发消息或收集私人收藏。

若出现打不开、数据丢失、重复发奖、二维码打开错误故事、正文自相矛盾或人物资料事实错误，先修复并重测对应流程，再扩大邀请。

本阶段尚未验证公开朋友圈传播能力。平台可能独立限制外部 H5 游戏链接；免费、免登录、取消传播奖励并不自动保证通行。参考 [微信外部链接内容管理规范](https://weixin.qq.com/agreement/weixin_external_links_content_management_specification)。公开传播前应按当时的平台要求和实际设备结果决定发布方式。

## 更新与旧结果

分享地址指向 `releases/v54/index.html#m=卡组ID`。该文件包括当时的卡片数据、评分、故事和绘图代码，应永久保留。未来改动另建新版本，不能覆盖 v54，否则朋友手中的旧结果将不再固定。

卡组链接和私人存档是两回事：链接只还原那一场戏；收藏、称号与次数需要主动导出 JSON 备份，不跨设备自动同步。
