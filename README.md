# DiaGacha·咫牌

戏剧混搭抽卡网页游戏。仓库收录现行完整版本 **v37**，以及各版本原始修改记录，便于后期整理。

在浏览器中直接打开 `index.html` 即可游玩。手机预览：

- [现行版](https://diagacha-81c856.deed.page/)
- [v37](https://v37--diagacha-81c856.deed.page/)

## 内容

- `index.html` — 现行完整游戏（777 张卡，单文件，v37）
- [CHANGELOG.md](CHANGELOG.md) — 修改记录总目
- `changelog/` — 各版本原始修改记录与相关说明，内容未改写
- `docs/SCORING.md` — 卡牌分数与「这台」评分规则
- `docs/RATES.md` — 抽卡出现率
- `docs/cards.json` — 卡牌数据

分数综合经典地位、传唱度与这一桌的组合关系，仅作游戏参考。
