# DiaGacha·咫牌

戏剧混搭抽卡网页游戏。仓库收录现行完整版本 **v38**，以及各版本原始修改记录，便于后期整理。

在浏览器中直接打开 `index.html` 即可游玩。已发布的旧版手机预览（v38 尚未部署到该托管地址）：

- [旧托管版](https://diagacha-81c856.deed.page/)
- [v37](https://v37--diagacha-81c856.deed.page/)

## 内容

- `index.html` — 现行完整游戏（777 张卡，单文件，v38）
- [CHANGELOG.md](CHANGELOG.md) — 修改记录总目
- `changelog/` — 各版本原始修改记录与相关说明，内容未改写
- `docs/SCORING.md` — 卡牌分数与「这台」评分规则
- [docs/RUBRIC.md](docs/RUBRIC.md) — 六维量表、剧作家/剧目参考与来源
- [docs/BALANCE_REPORT.json](docs/BALANCE_REPORT.json) — 十万包模拟与边界验证
- `docs/RATES.md` — 抽卡出现率
- `docs/cards.json` — 卡牌数据

v38 采用攻防均分、六维加权、同色共鸣与明确原作羁绊；数值是游戏编辑判断。32 张来源锚点与 745 张历史初评分开标记，未冒充全卡学术审定。
